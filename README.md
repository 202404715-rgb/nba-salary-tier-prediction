# 🏀 NBA Players Salary Tier Prediction Platform

A machine learning project that predicts whether an NBA player belongs to a **higher- or lower-salary tier** based on player and team characteristics.

Instead of predicting the exact salary amount, the project formulates the problem as a **binary classification task**, using the dataset's median salary as the threshold between the two salary tiers.

---

## 🎯 1. Business Goal

### The Problem

NBA player salaries are highly uneven, with a relatively small number of superstar contracts creating extreme values in the salary distribution.

Directly predicting the exact salary amount as a regression problem can therefore be challenging, particularly when the available dataset contains limited information about player performance and contract conditions.

### The Modeling Approach

To make the problem more suitable for the available data, salary was transformed into a binary target:

* **0 — Below Median Salary**
* **1 — Above Median Salary**

The median salary was used as the classification threshold, resulting in two relatively balanced target classes.

The objective is therefore:

> **Can player and team characteristics help identify whether an NBA player's salary is above or below the league's median salary?**

## 🛠️ 3. Data Cleaning & Feature Engineering

A preprocessing pipeline was developed to improve data quality and maintain a consistent modeling workflow.

### Height Standardization

Player height values were cleaned and converted into a consistent numerical representation where required.

### Feature Pruning

Features containing no useful information, including completely empty historical tracking variables, were removed from the modeling dataset.

### Missing-Value Handling

Missing physical attributes were handled using **median-based imputation**, with the preprocessing applied within the modeling workflow.

### Feature Scaling

Numerical features were standardized using:

`StandardScaler`

The preprocessing steps were incorporated into the validation workflow to reduce the risk of information from the validation folds influencing model training.

---

## 🤖 4. Machine Learning Model

### CatBoost Classifier

The project uses **CatBoost**, a gradient boosting algorithm that is particularly useful when working with datasets containing categorical variables.

This was a suitable choice because the dataset contains high-cardinality categorical features such as:

* `team`
* `college`

### Model Configuration

```python
model_cb = CatBoostClassifier(
    iterations=300,
    learning_rate=0.03,
    depth=4,
    l2_leaf_reg=5,
    cat_features=categorical_features,
    random_seed=42
)
```

---

## 🔬 5. Validation Strategy

Model performance was evaluated using **5-Fold Stratified Cross-Validation**.

Stratification was used to maintain a similar proportion of the two salary classes across the validation folds.

This provides a more reliable estimate of how the model performs across different subsets of the available data compared with evaluating it on a single train/test split.

### Cross-Validation Result

**Mean Cross-Validated Accuracy: 64.90% ± 6.65%**

The variation across folds is also important: it indicates that model performance changes depending on the subset of players used for validation.

---

## 📈 6. Model Performance

The classification results were approximately balanced across the two salary tiers:

| Salary Tier          | Precision | Recall | F1-Score | Support |
| -------------------- | --------: | -----: | -------: | ------: |
| Below Median         |      0.65 |   0.65 |     0.65 |     224 |
| Above Median         |      0.65 |   0.65 |     0.65 |     223 |
| **Overall Accuracy** |           |        | **0.65** | **447** |

### Key Takeaway

The model achieved approximately **65% classification accuracy**, which is above a naive 50/50 baseline for a balanced binary classification problem.

However, the result also shows that the available player-level features have **limited predictive power on their own**.

This is an important finding rather than a weakness to hide: salary is influenced by many factors that are not represented in the current dataset, including player performance, contract structure, market conditions, and career status.

## 🔎 7. Feature Importance

CatBoost feature importance was used to identify which variables contributed most strongly to the model's predictions.

### Top Features

| Feature | Importance |
| ------- | ---------: |
| Age     |     26.50% |
| Team    |     16.97% |
| College |     16.63% |
| Weight  |      7.68% |
| Height  |      4.92% |

### Interpretation

**Age — 26.50%**

Age was the strongest feature in the model, suggesting that career stage is associated with salary-tier differences in the dataset.

**Team — 16.97%**

Team was another important predictor, potentially reflecting differences in team payroll structures, roster composition, and market factors.

**College — 16.63%**

College contributed substantially to the model's predictions. This may reflect correlations between player background, career trajectory, and salary positioning rather than a direct causal relationship.

**Physical Characteristics**

Weight and height had smaller contributions compared with age, team, and college. This suggests that basic physical characteristics alone provide limited information about salary tier.

> **Important:** Feature importance indicates predictive contribution within this model. It does not establish that a feature directly causes a player's salary to increase or decrease.

## 💡 8. Key Analytical Insights

Several conclusions can be drawn from the modeling results:

1. **Salary tier is not determined by physical attributes alone.**
2. **Age appears to be an important predictor of salary positioning.**
3. **Team and college provide meaningful predictive information in this dataset.**
4. **The current feature set has limited ability to explain salary differences**, as reflected by the approximately 65% cross-validated accuracy.
5. **Additional performance and contract-related data would likely be more informative** than relying primarily on demographic and physical characteristics.

## 🚀 9. Future Improvements

The current model provides a baseline for salary-tier prediction, but its performance could potentially be improved through **data enrichment**.

### Player Performance

Adding basketball performance metrics could provide substantially more information about player value, such as:

* Points Per Game (PPG)
* Assists Per Game
* Rebounds Per Game
* Player Efficiency Rating (PER)
* Minutes Played
* Games Started
* Shooting percentages

### Career & Recognition

Additional career indicators could capture player status more effectively:

* All-Star selections
* All-NBA selections
* Awards
* Years of NBA experience

### Contract & Market Information

Contract-related features would provide a more direct representation of salary dynamics:

* Contract length
* Contract year
* Previous salary
* Free-agent status
* Team salary cap situation
* Contract type

These additions could provide the model with information that is much closer to the actual factors influencing NBA compensation.

## ⚠️ 10. Limitations

This project should be interpreted within the limitations of the available dataset.

### Limited Feature Set

The dataset does not contain detailed player performance or contract information, which are likely important drivers of salary.

### Historical Context

NBA salaries and league economics change over time. A player's salary should therefore be interpreted within the context of the season and market conditions in which the contract was established.

### Classification Simplification

Converting salary into two groups makes the problem easier to model and interpret, but it also removes information about the actual salary difference between players.

For example, two players can both be classified as "Above Median" while having substantially different salaries.

### Predictive, Not Causal

The model identifies relationships useful for prediction. Feature importance should not be interpreted as evidence of causal effects on salary.
